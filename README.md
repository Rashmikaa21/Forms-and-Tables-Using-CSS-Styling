# Forms and Tables Using CSS Styling

A beginner-friendly HTML and CSS practice project focused on creating and styling forms and tables using CSS.

## 📌 Topics Covered

- HTML Forms
- Input fields and labels
- Buttons and form controls
- CSS form styling
- HTML Tables
- Table borders and spacing
- Table headers and rows
- Colors and backgrounds
- Padding and alignment
- `:hover` and `:focus` pseudo-classes
- External CSS styling

## 🛠️ Technologies Used

- HTML5
- CSS3
